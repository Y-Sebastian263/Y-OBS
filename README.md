# Y-OBS ミニプレイヤー

REALITYの視聴者が、OBSの映像(ゲーム画面など)を**ミニプレイヤーで見ながらREALITYの配信を見られる**ようにするセットです。

```
OBS ──(RTMP・パスワード付き)──▶ 配信サーバー(VPS) ──▶ 視聴者のスマホ
                                                    ↑
                         視聴ページ: https://y-sebastian263.github.io/Y-OBS/
```

- 視聴者はページを開いて「ミニプレイヤーにする」を押すだけ(Androidは自動でホームへ、iPhoneはスワイプの案内が出る)
- 遅延: Android(Chrome)は低遅延モードで1秒前後、iPhone(Safari)は2〜3秒
  - Androidでも低遅延モードがつながらない回線では、自動で通常モードになります
- 音声: 最初は音なし。視聴者が🔊ボタンや音量スライダーで音ありにできます

| ファイル | 内容 |
|---|---|
| `index.html` / `config.js` | 視聴ページ(GitHub Pages)。接続先などの設定は `config.js` |
| `obs/y-obs-miniplayer.lua` | OBSスクリプト(配信先の設定と開始/停止) |
| `server/setup.sh` | 配信サーバー(VPS)の自動セットアップ |

---

## 1. 配信サーバーを用意する(初回だけ)

マイクラサーバーと同じさくらのVPS(153.127.64.17)に同居させます。
セットアップはマイクラ・既存のCaddy設定・ファイアウォールを壊さないように作ってあります
(Caddyfileはバックアップ後に追記、ufwは有効化しない、ポートが使用中なら何もせず中止)。

1. さくらのVPSのコントロールパネルで **パケットフィルター** を確認し、今の許可(SSH、マイクラのUDP 19132/19133 など)は残したまま、次を追加
   - TCP: 80、443、1935
   - TCP と UDP: 8189
2. PCのPowerShellからサーバーに入る
   ```
   ssh ubuntu@153.127.64.17
   ```
3. 次の1行を貼り付けて実行(sudoのパスワードを聞かれたら入力)
   ```
   curl -fsSL https://raw.githubusercontent.com/Y-Sebastian263/Y-OBS/main/server/setup.sh | sudo bash
   ```
4. 最後に出る **OBS送信パスワード** を控える(他人やチャットには貼らない)
   あとで見る時: `sudo cat /etc/y-obs/info.txt`

視聴ページの接続先(`config.js`)は `https://hls.153-127-64-17.sslip.io/...` と `https://rtc.153-127-64-17.sslip.io/...` に設定済みです。

## 2. OBSの設定(初回だけ)

1. OBS → **ツール → スクリプト → 「+」** で `obs/y-obs-miniplayer.lua` を追加
2. 「サーバーのアドレス」と「送信パスワード」を入力
3. おすすめの出力設定(設定 → 出力 → 出力モード「詳細」→ 配信)
   - キーフレーム間隔: **1秒**
   - ビットレート: **1500〜2000 Kbps**(30人くらいまで安定させるため)
   - CPU使用のプリセット: veryfast / チューン: zerolatency
   - 設定 → 映像: 1280×720、30fps

## 3. 毎回の使い方

1. スクリプト画面の **「配信開始」**(OBSの通常の配信開始ボタンでもOK)
2. 視聴者に `https://y-sebastian263.github.io/Y-OBS/` を案内
3. 終わったら **「配信停止」**

## 視聴者向けの注意

- **iPhone**: Safariで開く(アプリ内ブラウザやホーム画面に追加したアプリ版ではミニプレイヤー不可)
- **Android**: Chromeで開く。設定 → アプリ → Chrome → 「ピクチャー イン ピクチャー」を許可
- **iPhoneでREALITYに戻るとミニプレイヤーが止まる場合**: 🔊ボタンで 🔇(音なし)にすると止まりにくくなります

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 「配信はまだ始まっていません」のまま | OBSが配信中か(右下が緑)。スクリプトのサーバー・パスワード |
| OBSが接続できない | パケットフィルターで TCP 1935 を許可したか |
| Androidが低遅延にならない | パケットフィルターで 8189(TCP/UDP)を許可したか |
| サーバーの状態を見たい | `sudo systemctl status y-obs-mediamtx` / `sudo journalctl -u y-obs-mediamtx -n 50` |
